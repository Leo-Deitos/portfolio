Por que os painéis abaixo estão em HTML

Todos os painéis deste portfólio são clicáveis: você filtra, compara períodos e os números recalculam na hora, direto no navegador. Escolhi entregá-los assim por um motivo prático — um relatório do Power BI só é interativo para quem tem acesso ao ambiente onde ele está publicado. Print não se clica, e é justamente o clique que mostra se o modelo por trás está de pé.

O que está exposto aqui não é a ferramenta, é o que vem antes dela: a modelagem em esquema estrela, o tratamento feito no banco, as regras de negócio e a escolha do que merece virar indicador. Essa parte não muda de endereço. Os mesmos painéis são construídos por mim em Power BI — com modelo semântico, medidas DAX e conexão direta ao banco — e o caminho vale igualmente para Looker Studio, Tableau, Metabase ou Excel, conforme o que o cliente já usa.

Cada projeto abaixo nasceu de um banco de dados real, modelado do zero: os dados saem de SQL Server ou PostgreSQL, passam por ETL versionado e chegam ao painel já tratados. A camada visual é a última etapa — e a mais fácil de trocar.
